# Dashboard Plan de Desarrollo — Versalles, Valle del Cauca

Dashboard web para consulta y seguimiento del **Plan de Desarrollo Municipal de Versalles (Valle del Cauca)**, con información financiera y de avance físico.

## Publicación en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` a la raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona **main** y **/ (root)**.
6. Haz clic en **Save**.
7. Espera unos minutos a que GitHub publique el sitio.

La URL normalmente tendrá esta estructura:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

## Estructura

```text
/
├── index.html
└── README.md
```

## Características

- Listo para GitHub Pages.
- Diseño adaptable.
- Dashboard autocontenido.
- Chart.js embebido.
- No requiere servidor, base de datos ni instalación adicional.

## Actualización

Para publicar una nueva versión, reemplaza `index.html` en la rama `main`. GitHub Pages actualizará el sitio automáticamente.

## Nota

Antes de cada actualización pública, verifica que la información corresponda al corte oficial vigente.
