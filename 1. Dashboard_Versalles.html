⚙️ Configurar fuente de datos

Conecta este dashboard con una Hoja de Google publicada como CSV. Cada mes solo deberás pegar el nuevo archivo de presupuesto en la misma hoja y darle 🔄 Actualizar.

  1. Crea/abre una Google Sheet con las mismas columnas del archivo base de presupuesto
  2. Pega cada mes el archivo nuevo de presupuesto sobre los datos actuales
  3. Menú: Archivo → Compartir → Publicar en la web → CSV
  4. Copia la URL publicada (termina en output=csv) y pégala abajo
  5. Guarda · el dashboard releerá los datos al presionar Actualizar
💡 La URL debe terminar en output=csv

📂 Opción 0 — Carpeta Local

⭐ RECOMENDADA · Sin internet · Sin instalar nada

Apunta el dashboard a la carpeta donde guardas tus CSV de presupuesto. Cada mes guarda el nuevo CSV en la carpeta con un nombre diferente, presiona 🔃 Releer archivos para ver la lista y haz clic en 📥 Cargar este sobre el archivo que quieres usar. Chrome/Edge recuerda el acceso entre sesiones.

⚠️
Navegador no compatible Esta función requiere Chrome o Edge versión reciente. Firefox y Safari no lo soportan aún. Usa las Opciones A o B.
💡
Flujo mensual recomendado Cada mes, Planeación/Hacienda guarda el nuevo CSV en la carpeta configurada con un nombre diferente (ej. Libro1_Abril.csv, Libro1_Mayo.csv). Presiona 🔃 Releer archivos para ver la lista actualizada y haz clic en 📥 Cargar este sobre el archivo del mes que deseas. El anterior no se elimina — siempre puedes volver a él.

🔗 Opción A — Conectar Google Sheet

Si prefieres trabajar offline: copia todas las filas del archivo base de presupuesto (incluyendo encabezados) y pégalas aquí.
